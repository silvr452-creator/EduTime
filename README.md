# Система расписания колледжа

Полнофункциональный веб-интерфейс для управления расписанием колледжа с тремя ролями пользователей.

## 🎯 Возможности

### 👥 Роли пользователей

#### 📚 Студент
- Просмотр расписания своей группы
- Фильтрация по преподавателям и аудиториям
- Навигация по дням недели
- Автоматическая фильтрация по группе при входе

#### 👨‍🏫 Преподаватель  
- Просмотр своего расписания
- Фильтрация по группам
- Просмотр всех занятий на неделю
- Навигация по дням недели

#### 🛡️ Администратор
- Полный доступ к управлению расписанием
- Добавление новых занятий
- Редактирование существующих занятий
- Удаление занятий с подтверждением
- Поиск по группам и преподавателям
- Просмотр расписания в виде таблицы

## 🚀 Демо доступ

### Вход с разными ролями:

**Студент:**
- Email: `student@college.edu`
- Пароль: любой (минимум 6 символов)

**Преподаватель:**
- Email: `teacher@college.edu` или `petrov@college.edu`
- Пароль: любой (минимум 6 символов)

**Администратор:**
- Email: `admin@college.edu`
- Пароль: любой (минимум 6 символов)

## 📱 Экраны

### 1. Регистрация
- Выбор роли (Студент / Преподаватель / Администратор)
- Ввод ФИО, email, пароля
- Выбор группы (только для студентов)
- Валидация всех полей

### 2. Авторизация
- Вход по email и паролю
- Показ/скрытие пароля
- Валидация формы
- Восстановление пароля (заглушка)

### 3. Главный экран (Студент/Преподаватель)
- Навигация по дням недели
- Фильтры по группам, преподавателям, аудиториям
- Карточки занятий с информацией:
  - Название предмета
  - Время
  - Аудитория
  - Преподаватель
  - Тип занятия (лекция/практика/лабораторная)

### 4. Панель администратора
- Таблица всех занятий
- Поиск по группе или преподавателю
- Кнопка добавления занятия
- Редактирование занятий (иконка карандаша)
- Удаление занятий (иконка корзины)
- Диалог подтверждения удаления

### 5. Диалог добавления/редактирования занятия
- День недели
- Время занятия
- Название предмета
- Тип занятия (лекция/практика/лаборатория)
- Группа
- Преподаватель
- Аудитория
- Валидация всех полей
- Кнопка сохранения

## 🎨 Дизайн

- **Современный минималистичный стиль**
- **Градиентные фоны** для разных экранов
- **Цветовое кодирование:**
  - 🔵 Синий - студенты
  - 🟢 Зеленый - преподаватели  
  - 🟣 Фиолетовый - администраторы
- **Адаптивный дизайн** для мобильных и десктопов
- **Плавные анимации** и переходы
- **Toast уведомления** для обратной связи

## 🔄 Логика переходов

```
Вход → Выбор роли при регистрации → Главный экран (зависит от роли)
                                   ↓
                    Студент: Расписание группы
                    Преподаватель: Расписание преподавателя
                    Администратор: Панель управления
                                   ↓
                            Выход → Экран входа
```

## 🗄️ Данные из реальной БД

Приложение использует backend API для чтения/изменения расписания. Контракт подготовлен под PostgreSQL и ER-диаграмму (таблицы role/app_user/student/teacher/groups/subject/classroom/lesson).

- Настройка и контракт API: [`docs/DB_SETUP.md`](docs/DB_SETUP.md)
- Обязательная переменная окружения: `VITE_API_BASE_URL`
